ADS305 Lab 2: Data Preprocessing

What the notebook does, in order

These are the notebook's own section headings, in the order they appear in it.

  1. Importing Libraries
  2. Importing and Exploration of the dataset
  3. Checking the datatypes of the columns
  4. Converting the data types of columns
  5. Summary Statistics of the data
  6. Missing Values
  7. Outliers Treatment
  8. Encoding the Categorical Features, by two routes: pd.get_dummies and label encoding
  9. Creating new Derived Features

Then an Exercise, which is where adult.csv comes in.

Two sections do less than their titles promise. That's deliberate. Section 6 finds the missing values and reports that this dataset has none, so nothing is imputed. Section 7 plots the outliers.

What you need installed

pandas, numpy, matplotlib and scikit-learn. A standard Anaconda has all four. Section 8 imports scikit-learn, so it's not optional.

The setup sheet is in the Lab 1 folder, 0 ADS305-setup-read-this-first.html, and it covers installing all of this.

One thing to know before you start

The datatype names you see may not match the notebook's. The saved outputs were produced on pandas 3. If your Anaconda is older, several sections will print object where the notebook shows str, and datetime64[ns] where it shows datetime64[us].

Nothing's broken. It's the same thing under a different name. Read past it.
